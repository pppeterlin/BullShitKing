# 瞎掰王 🃏（本地部署版）

桌遊《瞎掰王》的**本機局網版本**——把它跑在自己的電腦上，大家用手機瀏覽器連進來一起玩。
零依賴，只要有 Python 3 就能跑。

## 怎麼玩（規則）

每回合會隨機分配角色：

| 角色 | 說明 | 怎麼決定 |
|------|------|---------|
| 🕵️ **老實人**（1 位）| 唯一看得到卡片背面「真正解釋」的人，要裝作大家都懂 | 每回合從大聰明以外的人**隨機**抽 |
| 🔍 **大聰明**（1 位）| 負責猜「誰是老實人」的人 | 依**加入順序（座位）固定輪換**，每人都輪得到 |
| 😏 **瞎掰者**（其餘）| 看不到答案，要靠瞎掰混過去 | 剩下的人 |

大聰明從房主開始，每回合往下一位傳，一輪結束再回到第一位。大廳與結算畫面都會預告「下一位大聰明是誰」。中途加入的人排在座位最後，輪到就會當。按「分數歸零，重新計分」時輪換也會從頭開始。

流程：

1. **選人數 / 加入** — 每支手機開網頁、輸入名字加入，房主（第一位加入的人 👑）按開始。

   > **中途加入**：回合進行到「預覽／閱讀／發言」時進來的人，會自動當**瞎掰者**並排進發言順序的最後；已經到「猜測／結算」才進來的人來不及參與，這回合顯示「觀戰中」，**下一回合自動編入**。
2. **題目預覽** — 出題後**先不倒數**，大家看題目。房主可按「**開始回合**」進入閱讀，或「**跳過這題**」換一張。
3. **閱讀（60 秒）** — 按下開始回合才倒數；只有老實人的卡片會翻到背面看到解釋，其他人只看到正面題目與提示。
4. **輪流發言** — 上方會標示現在輪到誰講，每個人輪流唬爛／解釋題目。
5. **大聰明猜測** — 選出他認為的老實人（要按確認）；還可以額外丟一張 **「聽你在瞎掰」卡** 給最多一位玩家。
6. **同步公布結果** — 所有手機同時跳出結果、公布正確解釋，並更新分數。房主可以按「下一回合」繼續，或用「🔄 分數歸零，重新計分」把大家的分數清零重開（不用退出房間重新加入）。

### 📢 隨時吐槽：「聽你在扯淡！」

遊戲中**點自己的頭像**（底部玩家列上有 📢 記號的那個，或畫面中間自己的大頭貼），就會對全場廣播一則「◯◯◯：聽你在扯淡！」的泡泡，所有人的手機都會看到它飄過去。

聽別人瞎掰到受不了的時候按就對了——**純娛樂，不影響分數**，也跟大聰明的「聽你在瞎掰」卡完全無關。每人有 1.5 秒冷卻防洗版，泡泡 4 秒後自動消失。

### 計分（`D` = 卡片難度分，1～3）

**只有「被大聰明選中的那個人」拿得到難度分**，沒被選到的人不加分：

- 大聰明**猜中**老實人 → 老實人 `+D`、大聰明也 `+D`
- 大聰明**猜錯**（選到瞎掰者）→ **只有被選中的那位瞎掰者** `+D`（成功騙到大聰明），其他瞎掰者不加分
- **「聽你在瞎掰」卡**（只影響大聰明自己）：丟到瞎掰者 → 大聰明 `+1`；丟到老實人 → 大聰明 `-3`（冤枉好人）；不丟 → 沒事

回合結束時會**對所有人公布卡片背面的正確解釋**。

> 瞎掰卡的加減分寫在 `server.py` 的 `CALLOUT_HIT_BONUS` / `CALLOUT_MISS_PENALTY`。

## 怎麼執行

```bash
python3 server.py
```

（有 uv 的話：`uv run server.py`，零依賴不用先裝東西。）

啟動後畫面會顯示兩個網址：

```
本機：      http://localhost:8000
手機（同網）：http://192.168.x.x:8000   ← 手機用這個
```

- **手機要跟這台電腦連到同一個 Wi-Fi**，用瀏覽器開「手機（同網）」那個網址就能加入。
- 想換連接埠：`PORT=9000 python3 server.py`
- 一個人測試：`python3 server.py --test`（見下方「測試模式」）
- 結束：在終端機按 `Ctrl+C`

### 測試模式（一個人模擬整場）

```bash
python3 server.py --test      # 或 TEST_MODE=1 python3 server.py
```

- 開機自動放 2 個 🤖 機器人，你一個人加入就湊滿 3 人，可以直接開局。
- 頁面頂端的「🧪 切換視角」列：點任一位玩家就切成他的畫面（看老實人答案、當大聰明猜測、輪流發言都行），每個人旁邊會標示本回合的角色；「＋機器人」可再加人測多人情境。
- 任何視角都有房主權限。
- 存檔寫到 `state.test.json`，每次啟動都是乾淨房間，**不會動到正式的 `state.json`**。
- 一般啟動（不帶 `--test`）完全不受影響，也看不到這排切換列。

### 重啟不會弄丟房間

玩家名單與分數會自動存到專案目錄下的 `state.json`（加入、開始回合、結算、重置時各存一次），重啟後會自動接回來：

```
  已接回上次的房間：5 位玩家
    🐰 zzn(4分)、🐻 Peter(1分)、🐱 CK(2分)、🐶 hmz(6分)、🦊 醒醒(0分)
```

因為連玩家 id 都一樣，**手機不用重新加入也不用重整**——頁面每秒輪詢一次，伺服器回來的下一秒就自己接上了（但若前端有改版，還是要重整才會拿到新的畫面）。

會接回來的：玩家、分數、頭像、房主、大聰明輪到誰、第幾回合。
**不會**接回來的：進行到一半的那個回合（角色、題目、倒數計時器）——重啟後一律回到大廳，由房主重開一局。所以要重啟的話，挑「大廳」或「結算」的時候最順。

想從乾淨的空房間開始，砍掉存檔再啟動就好：

```bash
rm state.json && python3 server.py
```

- 換存檔位置：`STATE_FILE=/path/to/room.json python3 server.py`
- 存檔壞掉或格式不對不會讓伺服器啟動失敗，只會印一行警告然後開空房間。

> 若手機連不上，多半是電腦防火牆擋了，或電腦開了 VPN。macOS 可到「系統設定 → 網路 → 防火牆」允許 Python 連入，VPN 則建議暫時關閉或開啟「允許區域網路」。

### 題庫預覽 / 審題

```bash
python3 preview.py      # 預設 port 8100
```

純預覽模式，只顯示「瞎掰者看得到的卡片」（題目＋難度＋提示，**看不到答案**）。可用「棄用」按鈕把不喜歡的題標記掉，結果會存進 `棄用清單.txt`。

## 題目難度設計

難度不是看「題目多冷門」，而是看**瞎掰者能不能編出合理解釋**——越好瞎掰、大家講得越像，就越難被大聰明識破，分數也越高。提示是用來「救」難瞎掰的題，讓大家有方向可編。

| 難度 | 提示 | 特性 |
|------|------|------|
| ★ | 1 個領域名詞（如「圍棋」「釀酒」）| 詞很難瞎掰，給一個方向救它 |
| ★★ | 3 個名詞（1 真 2 假，方向不同）| 有點難度，假提示製造岔路 |
| ★★★ | 無提示 | 詞本身就好自由發揮 |

> ★★ 的三個提示刻意跨不同題材（如 `神話／遊戲／小說`），讓瞎掰者有更多角度可編。

**兩個原則**：① 題目一律是「可以被解釋的名詞」，不是敘述句或附加事實；② 太多人都知道意思的詞不收（沒得玩）。

## 題目類別

目前約 **580 題**，分七類：

| 類別 | 說明 | 例子 |
|------|------|------|
| **專業詞彙** | 各行冷門術語、行話 | 榫卯、走錨、疏果、華彩 |
| **歷史事件** | 冷門、詼諧、反差的真實事件 | 鴯鶓戰爭、大月球騙局、皇帝諾頓 |
| **神話童話** | 冷門的世界神話與民間故事 | 爛柯、葉限、烏特加德之旅、天岩戶 |
| **網路梗** | 流行網路用語／迷因 | 空耳、歐皇、毒奶、凡爾賽文學 |
| **冷知識** | 有命名的現象 / 概念 | 天使的份額、姆潘巴現象、聯覺 |
| **冷僻字** | 冷僻但有明確意思的詞 | 饕餮、齟齬、氍毹 |
| **其他** | 悖論、思想實驗、錯覺、傳說生物 | 忒修斯之船、潘洛斯階梯、銜尾蛇 |

**不收的題目**：字面就看得懂的日常詞（勾芡、過油、川燙）、太多人知道的效應與現象（安慰劑效應、共振、毛細現象），以及只有單一角色名的神話題（知道人物不有趣，知道一整個故事才有趣——所以神話類一律用「故事」當題目）。

## 檔案結構

```
BullshitKing/
├── server.py        # 遊戲伺服器 + 邏輯（純標準函式庫，零依賴）
├── preview.py       # 題庫預覽 / 審題工具
├── cards.py         # 題庫（~580 題）；末尾有星等平衡的 override 區塊
├── static/          # 前端（index.html / style.css / app.js）
├── 題庫規劃.md      # 題庫的難度與收錄設計文件
└── README.md
```

## 之後可以調整

- **題庫**：在 `cards.py` 的 `CARDS` 增修（`topic` 題目、`description` 解釋、`difficulty` 難度、`hints` 提示）。
- **星等比例**：調整 `cards.py` 末尾 override 區塊的清單。
- **參數**：閱讀秒數（`server.py` 的 `READING_SECONDS`）、最少人數、計分細則。
