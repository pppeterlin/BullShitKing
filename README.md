# 瞎掰王 🃏（本地部署版）

桌遊《瞎掰王》的**本機局網版本**——把它跑在自己的電腦上，大家用手機瀏覽器連進來一起玩。
零依賴，只要有 Python 3 就能跑。

## 怎麼玩（規則）

每回合會隨機分配角色：

| 角色 | 說明 |
|------|------|
| 🕵️ **老實人**（1 位）| 唯一看得到卡片背面「真正解釋」的人，要裝作大家都懂 |
| 🔍 **大聰明**（1 位）| 負責猜「誰是老實人」的人 |
| 😏 **瞎掰者**（其餘）| 看不到答案，要靠瞎掰混過去 |

流程：

1. **選人數 / 加入** — 每支手機開網頁、輸入名字加入，房主（第一位加入的人 👑）按開始。
2. **題目預覽** — 出題後**先不倒數**，大家看題目。房主可按「**開始回合**」進入閱讀，或「**跳過這題**」換一張。
3. **閱讀（60 秒）** — 按下開始回合才倒數；只有老實人的卡片會翻到背面看到解釋，其他人只看到正面題目與提示。
4. **輪流發言** — 上方會標示現在輪到誰講，每個人輪流唬爛／解釋題目。
5. **大聰明猜測** — 選出他認為的老實人（要按確認）；還可以額外丟一張 **「聽你在瞎掰」卡** 給最多一位玩家。
6. **同步公布結果** — 所有手機同時跳出結果，並更新分數。

### 計分（`D` = 卡片難度分，1～3）

- 大聰明**猜中**老實人 → 大聰明 `+D`、老實人 `+D`
- 大聰明**猜錯** → 每位瞎掰者 `+D`（成功騙過大聰明）
- **「聽你在瞎掰」卡**：丟到瞎掰者 → 那位瞎掰者 `-D`（被抓包）；丟到老實人 → 大聰明 `-D`（冤枉好人）；不丟 → 沒事

## 怎麼執行

```bash
python3 server.py
```

（有 uv 的話：`uv run server.py`，零依賴不用先裝東西。）

啟動後畫面會顯示兩個網址：

```
本機：      http://localhost:8000
手機（同網）：http://192.168.x.x:8000   ← 手機用這個
```

- **手機要跟這台電腦連到同一個 Wi-Fi**，用瀏覽器開「手機（同網）」那個網址就能加入。
- 想換連接埠：`PORT=9000 python3 server.py`
- 結束：在終端機按 `Ctrl+C`

> 若手機連不上，多半是電腦防火牆擋了，或電腦開了 VPN。macOS 可到「系統設定 → 網路 → 防火牆」允許 Python 連入，VPN 則建議暫時關閉或開啟「允許區域網路」。

### 題庫預覽 / 審題

```bash
python3 preview.py      # 預設 port 8100
```

純預覽模式，只顯示「瞎掰者看得到的卡片」（題目＋難度＋提示，**看不到答案**）。可用「棄用」按鈕把不喜歡的題標記掉，結果會存進 `棄用清單.txt`。

## 題目難度設計

難度不是看「題目多冷門」，而是看**瞎掰者能不能編出合理解釋**——越好瞎掰、大家講得越像，就越難被大聰明識破，分數也越高。提示是用來「救」難瞎掰的題，讓大家有方向可編。

| 難度 | 提示 | 特性 |
|------|------|------|
| ★ | 1 個領域名詞（如「圍棋」「釀酒」）| 詞很難瞎掰，給一個方向救它 |
| ★★ | 3 個名詞（1 真 2 假，方向不同）| 有點難度，假提示製造岔路 |
| ★★★ | 無提示 | 詞本身就好自由發揮 |

> ★★ 的三個提示刻意跨不同題材（如 `神話／遊戲／小說`），讓瞎掰者有更多角度可編。

**兩個原則**：① 題目一律是「可以被解釋的名詞」，不是敘述句或附加事實；② 太多人都知道意思的詞不收（沒得玩）。

## 題目類別

目前約 **580 題**，分六類：

| 類別 | 說明 | 例子 |
|------|------|------|
| **專業詞彙** | 學術效應/定律 + 各行冷門術語、行話 | 巴納姆效應、榫卯、走錨、貴腐 |
| **歷史事件** | 冷門、詼諧、反差的真實事件 | 鴯鶓戰爭、大月球騙局、皇帝諾頓 |
| **神話童話** | 冷門的希臘/北歐/世界神話小故事 | 西西弗斯、法夫尼爾、報喪女妖 |
| **冷知識** | 有命名的現象 / 概念 | 天使的份額、姆潘巴現象、聯覺 |
| **冷僻字** | 冷僻但有明確意思的詞 | 饕餮、齟齬、氍毹 |
| **其他** | 悖論、思想實驗、錯覺、傳說生物 | 忒修斯之船、潘洛斯階梯、銜尾蛇 |

## 檔案結構

```
BullshitKing/
├── server.py        # 遊戲伺服器 + 邏輯（純標準函式庫，零依賴）
├── preview.py       # 題庫預覽 / 審題工具
├── cards.py         # 題庫（~580 題）；末尾有星等平衡的 override 區塊
├── static/          # 前端（index.html / style.css / app.js）
├── 題庫規劃.md      # 題庫的難度與收錄設計文件
└── README.md
```

## 之後可以調整

- **題庫**：在 `cards.py` 的 `CARDS` 增修（`topic` 題目、`description` 解釋、`difficulty` 難度、`hints` 提示）。
- **星等比例**：調整 `cards.py` 末尾 override 區塊的清單。
- **參數**：閱讀秒數（`server.py` 的 `READING_SECONDS`）、最少人數、計分細則。
